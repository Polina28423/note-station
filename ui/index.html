Ссылка на сайт

Клик по ссылке открывает сайт в системном браузере. Для изменения адреса установите курсор в ссылку и нажмите Ctrl+K.

Проверка орфографии

В смешанном режиме язык определяется по предложению и характерным буквам. Для спорных фрагментов выделите текст в редакторе, откройте проверку и выберите область «Выделенный текст» и нужный язык. Код и защищённые фрагменты пропускаются.

Исправления меняют только черновик. Сохраните заметку на NAS обычной кнопкой сохранения.
